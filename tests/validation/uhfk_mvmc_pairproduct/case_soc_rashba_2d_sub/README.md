# case_soc_rashba_2d_sub — 2D 6x4 Rashba SOC + sublattice folding fixture

2D square Hubbard 6x4 lattice with Rashba SOC and SubShape `[2, 2, 1]`
(spec §4.2.2). PBC in both directions; folded BZ is `[3, 2, 1]`. The
v3.1 SOC branch of the bridge (`enable_spin_orbital = true`, orbital
index in `Transfer.dat` carries spin as `2 * orb + spin`) plus the
non-self canonical block path (folded x direction has length 3, so
`k_x = 0` is self and `k_x = ±2π/3` form a non-self canonical pair;
the folded y direction has length 2 and is fully self canonical).
This is the fixture that exercises both self and non-self canonical
blocks simultaneously with SubShape > `[1, 1, 1]` active.

Parameters:

- `t = 1.0`, `U = 2.0`, Rashba `α_R = 0.5`.
- `CellShape = [6, 4, 1]`, `SubShape = [2, 2, 1]` → 24 physical sites,
  48 spin-orbital labels, 6 folded k-points.
- `Ncond = 8`: verified by `scripts/soc_pilot_gap.py` to sit below a
  gap of ~1.05e-1 at t=1, alpha=0.5, U=2.
- Boundary: PBC in all three directions.

## Ncond gap check

`Transfer.dat`, `OneBodyG.dat` are generated by

```bash
python scripts/emit_rashba_transfer.py --cell 6,4,1 --t 1.0 --alpha 0.5 \
    --out case_soc_rashba_2d_sub/Transfer.dat
python scripts/emit_onebodyg_full_soc.py --cell 6,4,1 \
    --out case_soc_rashba_2d_sub/OneBodyG.dat
```

The pilot

```bash
PYTHONPATH=src python scripts/soc_pilot_gap.py \
    --case tests/validation/uhfk_mvmc_pairproduct/case_soc_rashba_2d_sub \
    --ncond 6,8,10,12,14
```

reports (`t=1, α=0.5, U=2`, initial Green = zeros):

- `Ncond=6`:  gap = 5.540e-01 (OK)
- `Ncond=8`:  gap = 1.053e-01 (OK)  ← fixture choice per spec §4.2.2
- `Ncond=10`: gap = 1.349e-01 (OK)
- `Ncond=12`: gap = 2.692e-01 (OK)
- `Ncond=14`: gap = 7.972e-01 (OK)
